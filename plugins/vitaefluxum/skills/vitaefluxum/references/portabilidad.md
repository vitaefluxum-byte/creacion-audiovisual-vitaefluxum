# Portabilidad

El núcleo es la carpeta vitaefluxum que contiene SKILL.md, references, assets y agents. No depende de herramientas personales del creador.
- El repositorio conserva el empaquetado del plugin existente para entornos compatibles.
- El ZIP independiente contiene la carpeta de skill completa. Que una aplicación pueda importar skills depende de su versión y funciones; verifica su procedimiento actual antes de dar pasos de instalación.
- En Claude u otro asistente compatible, utiliza su mecanismo de skills y conserva los archivos relativos. No afirmes que cualquier IA puede instalar un ZIP.
- En entornos que solo admiten documentos, el texto puede servir como referencia, sin garantizar activación automática ni acceso a todas las imágenes.
- Generar imágenes requiere una herramienta de imágenes. Blender requiere ejecución local o una conexión que lo permita. La instalación de la skill por sí sola no aporta esas herramientas.
- Para mostrar ejemplos, resuelve sus rutas relativas al archivo que los enlaza y utiliza el visor o adjunto del entorno. Si necesita una ruta pública de trabajo, copia solo el recurso correspondiente. No regeneres la imagen ni reveles rutas internas de instalación.
- Si no puedes mostrar un recurso, explica la limitación y ofrece un archivo accesible cuando exista. No inventes enlaces.
